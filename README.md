# My Cat 🐱

A cozy interactive 3D web scene built with Three.js.

## Features
- Cozy 3D home interior
- Cute chunky sleeping cat
- Purring/breathing animation
- Click the cat to hear a synthesized meow
- Drag to look around
- Scroll to zoom
- Responsive desktop/mobile layout
